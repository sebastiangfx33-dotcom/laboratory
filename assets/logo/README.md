# Logotipo Original de LABORATORY

Para cumplir estrictamente con las normas de identidad visual de **LABORATORY**:

1. Coloca el archivo original del logotipo proporcionado por el propietario en esta carpeta con el nombre:
   `laboratory-logo.svg` (o actualiza `logoSrc` en `js/config.js` si utilizas `.png` o `.webp`).
2. El sistema cargará automáticamente el archivo original respetando su geometría, proporciones y tipografía exacta sin rediseñarlo ni deformarlo.
3. Mientras el archivo original no se encuentre aún en esta carpeta, la interfaz muestra un contenedor de recurso pendiente claramente identificado y solicita su incorporación.
